# React 系统学习计划（Vue 开发者版）

面向有多年 Vue 生态经验、React 只有基础使用经验的前端工程师。

目标：在 **18 周 / 108 个课时** 内，系统掌握现代 React（19.3）、主流生态、Next.js 16 与 RSC，并理解 Fiber、调度器、Hooks、Suspense 等底层实现原理；同时服务于**工作落地**和**面试跳槽**。

## 基本设定

- 每天约 **2 小时**，每周 **6 天**，留 1 天机动/休息
- 18 周共 **108 个课时**，按课时推进，不绑死日历
- 中文讲解 + Vue 对照 + 可运行代码 + 动手练习 + 闭卷自测
- 版本基线：**React 19.3、Next.js 16**（2026-11 核对）；具体 API 以官方最新文档为准
- 学习节奏：理论 → 动手 → 自测 → 复盘；每个阶段都有可验收产出

## 怎么用这套系统

1. **第一次**：读一遍 [learning-plan.md](learning-plan.md)，然后对我说 **“继续 react 学习”**。
2. **每次学习**：我会读取 [progress.md](progress.md)，确定下一个课时，生成当天学习单 `daily/day-XXX.md`，并在对话里带你完成 2 小时的学习。
3. **进度真实性**：只有你确认完成，我才会勾选进度；没完成或跳过的内容会如实保留。
4. **时间不够**：直接说“今天只有 45 分钟”，我会给一个保留核心闭环的压缩版。
5. **节奏调整**：觉得太快、太慢、某个主题想深入，或者工作临时打断，直接说，我会调整后续计划并写明原因。
6. **随时提问**：学习中任何疑问都可以打断，不理解的先记到 `progress.md` 的疑问清单，不让它滚雪球。

## 六个阶段

| 阶段 | 周期 | 内容 | 核心产出 |
|---|---|---|---|
| 0 · 起跑 | 第 1 周 | 诊断、Vue→React 心智模型、工程基线 | 学习系统 + 弱项清单 |
| 1 · 核心 | 第 2–5 周 | 组件、状态、Effect、Hook、组件模式、性能、测试 | 3 个练习项目 |
| 2 · 并发与新范式 | 第 6–7 周 | 并发渲染、Transition、React 19 Actions、Compiler | 性能实验 + 评论流项目 |
| 3 · 生态与工程化 | 第 8–11 周 | 状态管理、TanStack Query、路由、表单、样式、测试、CI | 可上线的 Admin 应用 |
| 4 · Next.js 与 RSC | 第 12–13 周 | App Router、缓存、Server Actions、RSC、SSR/水合 | 全栈应用 + 选型报告 |
| 5 · 底层原理 | 第 14–16 周 | 手写 mini-React、Fiber、Scheduler、Lane、Hooks、Suspense 源码 | mini-React + 源码笔记 |
| 6 · 综合与输出 | 第 17–18 周 | Capstone、迁移策略、面试专题、技术输出 | 线上项目 + 文章/分享 |
