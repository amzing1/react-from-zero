## 1. 核心概念（35 min）

### 1.1 惰性初始化

```tsx
// ❌ 每次 render 都会执行 expensive()
const [data, setData] = useState(expensive())

// ✅ 只在首次挂载执行一次
const [data, setData] = useState(() => expensive())
```

- `useState` 的参数如果是**函数**，React 会把它当成初始化函数，只在首次渲染调用
- 适用：昂贵计算、读 localStorage、解析大 JSON
- 初始化函数必须是**纯函数**；不要在里面发请求/改外部状态
- 注意：`useState(() => () => ...)` 这种返回函数的场景，要再包一层

### 1.2 更新函数与批处理

```tsx
setN(n + 1)          // 基于本次 render 的快照
setN((x) => x + 1)   // 基于队列中的最新值
```

- 同一事件里的多次 setState 会被**批处理**，只触发一次 render
- 更新函数按入队顺序执行：0 → 1 → 2 → 3
- 初始值不是一次更新；三次 updater = 加 3
- 下一次状态依赖上一次状态时，**优先用更新函数**，避免闭包旧值

### 1.3 不可变更新

**数组**：

```tsx
// 添加
setItems([...items, newItem])

// 删除
setItems(items.filter((item) => item.id !== id))

// 更新某一项
setItems(items.map((item) =>
  item.id === id ? { ...item, done: !item.done } : item
))

// 排序/反转（不要用 sort/reverse 原地修改）
setItems(items.toSorted((a, b) => a.order - b.order))
setItems(items.toReversed())
```

**对象**：

```tsx
setUser({ ...user, name: 'Ada' })
```

**嵌套对象**（每一层都要复制）：

```tsx
setUser({
  ...user,
  profile: {
    ...user.profile,
    address: {
      ...user.profile.address,
      city: 'Shanghai',
    },
  },
})
```

**常见 mutation bug**：

```tsx
items.push(newItem)
setItems(items)          // ❌ 同一个引用，Object.is 相等，不重渲染

item.quantity++
setItems([...items])     // ❌ 外层新数组，但 item 还是被改了；旧快照被污染
```

### 1.4 派生状态 vs 存储状态

```tsx
// ❌ 冗余 state：需要手动同步
const [total, setTotal] = useState(0)
const [count, setCount] = useState(0)

// ✅ render 时派生
const total = items.reduce((sum, item) => sum + item.price * item.quantity, 0)
const count = items.reduce((sum, item) => sum + item.quantity, 0)
```

- 能从 state/props 算出来的，不要另存 state
- `useState` 的初始值只在首次渲染使用；props 变化不会重置 state
- 需要“切换实体时重置 state”时，用 `key`

### 1.5 常见 bug 清单

1. 直接改 state（push/splice/sort/赋值）→ 不重渲染
2. 只展开外层，内层仍被修改 → 旧快照污染
3. 用 `setState` 的值形式更新依赖前值的状态 → 闭包旧值
4. 把 props 复制进 state → props 变了 state 不同步
5. 把派生值存进 state → 双份数据不同步
6. 初始化函数里做副作用
7. 认为 `useState` 初始值会在每次渲染更新

### 1.6 Vue 对照

| Vue | React |
|---|---|
| `ref` / `reactive` 直接修改 | 必须返回新引用；直接改不触发更新 |
| `computed` 自动缓存派生值 | render 时直接算；需要时再 useMemo |
| `watch` 监听变化 | useEffect（020）；派生优先 |
| `props` 变化自动同步到本地 | useState 初始值只用于首次；用 key 或派生 |
| `v-model` | value + onChange（015） |

## 4. 总结与复习卡（10 min）

### 今日一句话总结

`useState` 初始值只用于首次渲染（惰性初始化可避免每次 render 重算）；更新函数拿队列最新值；不可变更新要每层返回新引用；派生值不进 state。
