## 4. 周笔记 + 第 3 周预习（10 min）

### 第 2 周周笔记

**学到的 3 件事**

1. JSX 是 `jsx(type, props, key)` 的语法糖；组件是函数，大小写决定 host 元素还是组件引用。
2. render 是算 UI（可中断、必须纯、开发双调用），commit 是改 DOM（同步、一次、四子阶段）；state 是快照，更新排队。
3. key 是身份不是位置；事件委托在根容器；过滤结果派生、受控输入、组件边界。

**最薄弱的 2 点**

1. 更新函数与批处理的口算（1 vs 3）——两次写成 4，需要写队列而不是心算。
2. index key 的复用机制——仍会滑成“跳过 DOM 更新”。

**项目 A 的一个改进**

把过滤逻辑抽离成 `filterNotes` 纯函数，让 028 可以直接写单元测试。
