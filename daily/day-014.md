## 1. 核心概念（35 min）

### 1.1 自动批处理

```tsx
function handleClick() {
  setA(1)
  setB(2)
  setC(3)
  // 一次 render、一次 commit
}
```

- React 18+：**自动批处理**覆盖事件处理、Promise、`setTimeout`、原生事件监听
- React 17 及以前：只在 React 事件处理里批处理；`setTimeout`/Promise 里每次 setState 都可能触发一次 render
- 批处理是“合并成一次 render”，不是“合并成一个值”；更新队列仍按顺序执行
- StrictMode 开发环境：render 函数可能执行两次，commit 仍一次

### 1.2 更新函数与队列

```text
三次 setN(n + 1)，n=0：  [1, 1, 1] → 1
三次 setN(x => x + 1)：  0→1→2→3 → 3
```

- 值形式捕获当次 render 的快照
- 函数形式拿到队列里的最新值
- 下一次状态依赖上一次状态时，**用函数形式**
- 批处理 + 更新函数 = 一次 render 内按顺序应用队列

### 1.3 flushSync

```tsx
import { flushSync } from 'react-dom'

flushSync(() => setA(1))
flushSync(() => setB(2))
// 两次 render/commit，而不是一次
```

- 强制同步刷新，退出批处理
- 代价：额外的 render/commit、破坏并发渲染的调度；不要日常使用
- 适用：更新后立刻测量 DOM、与第三方库集成等少数场景
- 不要在 render/lifecycle 里调用；在事件处理/Effect 里谨慎使用

### 1.4 状态提升

**单一数据源**：多个组件需要同一份数据时，把 state 提升到最近的公共父级。

```tsx
function Calculator() {
  const [temperature, setTemperature] = useState('')
  const [scale, setScale] = useState<'c' | 'f'>('c')

  const celsius = scale === 'f' ? tryConvert(temperature, toCelsius) : temperature
  const fahrenheit = scale === 'c' ? tryConvert(temperature, toFahrenheit) : temperature

  return (
    <>
      <TemperatureInput
        scale="c"
        temperature={celsius}
        onTemperatureChange={(t) => { setScale('c'); setTemperature(t) }}
      />
      <TemperatureInput
        scale="f"
        temperature={fahrenheit}
        onTemperatureChange={(t) => { setScale('f'); setTemperature(t) }}
      />
      <BoilingVerdict celsius={parseFloat(celsius)} />
    </>
  )
}
```

- props 向下，回调向上
- 子组件受控：`value` + `onChange`
- 派生值（另一个温度、沸腾判断）在父级 render 时算，不另存
- **状态就近**：不要无脑提升到 App；提升太高会导致 prop drilling 和不必要的重渲染

### 1.5 常见坑

1. 两个兄弟各存一份相同数据 → 不同步（应提升）
2. 提升过高 → 层层传 props、父级重渲染拖累整棵树
3. 只存一份“源状态”，另一个用派生 → 避免双份数据
4. 受控组件只写 `value` 不写 `onChange` → 输入框只读
5. 依赖前值的更新用值形式 → 闭包旧值
6. 滥用 `flushSync` → 性能与调度问题

### 1.6 Vue 对照

| Vue | React |
|---|---|
| `v-model` 双向绑定 | `value` + `onChange`（显式） |
| `defineModel` | 受控 props + 回调 |
| 子组件 `emit` 通知父级 | 回调 prop |
| 状态提升同样存在 | 提升到最近公共父级 |
| `provide/inject` | Context（017） |
| 响应式自动追踪 | 显式传递，依赖引用变化 |
