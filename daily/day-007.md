## 1. 核心概念（35 min）

### 1.1 心智模型：JSX 不是模板，是表达式

- JSX 是 `jsx()` 调用的语法糖，React 17+ 走**自动运行时** `react/jsx-runtime`，不需要 `import React`
- 编译形态：`jsx(type, props, key)`；多个静态 children 用 `jsxs`；开发环境用 `jsxDEV`
- `children` 只是 `props.children`；`key` 不进 props，作为 `jsx()` 的第三个参数
- `{}` 里只能放**表达式**，不能放语句（`if` / `for` 不行）；条件用 `&&` / 三元，列表用 `map`
- 组件即函数：函数组件 = 返回 React 元素的函数，每次 render 重新执行，没有 `this`；运行时实例记录是 fiber

### 1.2 Vue 对照

| Vue | React | 关键差异 |
|---|---|---|
| SFC `<template>` 编译成 render 函数 → vnode | JSX 编译成 `jsx()` 调用 → element 对象 | 模板是 DSL；JSX 是 JS 表达式 |
| `v-if` / `v-else` | `&&` / 三元 | 没有指令，只有表达式 |
| `v-for` + `:key` | `array.map` + `key` | key 由 `jsx()` 第三参传入 |
| `<slot>` / 具名插槽 | `children` / props | children 也是 props |
| `<template>` 多根 | Fragment `<>...</>` | Fragment 不产生 DOM |
| 编译期静态提升、patch flags | 运行时 reconcile + Compiler 优化 | 优化时机不同 |

### 1.3 API / 语法

```tsx
// 编译前
<Button size="sm" onClick={save}>
  Save
</Button>

// 编译后（自动运行时，简化）
jsx(Button, { size: 'sm', onClick: save, children: 'Save' })
```

```tsx
// 表达式边界
const el = (
  <>
    {count > 0 && <Badge count={count} />}   {/* 注意 0 的坑 */}
    {done ? <span>done</span> : null}
    <ul>{users.map((u) => <li key={u.id}>{u.name}</li>)}</ul>
  </>
)
```

### 1.4 常见坑与最佳实践

- `count && <X />` 在 `count === 0` 时会渲染 `0`；用 `count > 0 &&` 或三元
- `null` / `undefined` / 布尔值不渲染；`0` 和空字符串会渲染
- 对象不能直接作为 child（`Objects are not valid as a React child`）
- 组件必须大写开头：`<Foo />` 编译为变量引用 `jsx(Foo, ...)`，`<foo />` 编译为字符串 tag
- 短语法 Fragment 不能带 `key`；需要 key 时写 `<Fragment key={...}>`
- `onClick={handleClick}` 传函数，不是 `handleClick()`；事件对象、参数用箭头函数包一层
- `style={{ color: 'red' }}`、`className`、`htmlFor`
