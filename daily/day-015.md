## 1. 核心概念（35 min）

### 1.1 受控 vs 非受控

| | 受控 | 非受控 |
|---|---|---|
| 值存在哪 | React state | DOM |
| 写法 | `value` + `onChange` | `defaultValue` + ref / FormData |
| 实时校验、格式化、联动 | ✅ | ❌（要手动读 DOM） |
| 代码量 | 多 | 少 |
| 文件输入 | 不能受控 | 必须非受控 |
| 提交时读取 | 直接读 state | `FormData` / ref |

### 1.2 各控件的受控写法

```tsx
// 文本
<input value={form.name} onChange={handleChange} />

// textarea：用 value，不是 children
<textarea value={form.bio} onChange={handleChange} />

// select：value 放在 select 上
<select value={form.country} onChange={handleChange}>
  <option value="cn">中国</option>
</select>

// radio：checked 判断
<input
  type="radio"
  name="gender"
  value="male"
  checked={form.gender === 'male'}
  onChange={handleChange}
/>

// checkbox：checked，不是 value
<input
  type="checkbox"
  name="agree"
  checked={form.agree}
  onChange={handleChange}
/>

// 文件：必须非受控
<input type="file" onChange={(e) => setFile(e.target.files?.[0] ?? null)} />
```

### 1.3 多字段：对象 state + name

```tsx
const [form, setForm] = useState({
  username: '',
  email: '',
  bio: '',
  agree: false,
})

function handleChange(
  e: ChangeEvent<HTMLInputElement | HTMLTextAreaElement | HTMLSelectElement>,
) {
  const { name, value, type } = e.target
  const checked = (e.target as HTMLInputElement).checked
  setForm((prev) => ({
    ...prev,
    [name]: type === 'checkbox' ? checked : value,
  }))
}
```

- 字段之间有关联（同一张表单）→ 一个对象 state
- 字段完全独立 → 可以拆成多个 useState
- 永远不可变更新：`{ ...prev, [name]: value }`

### 1.4 校验与提交

```tsx
function validate(form: FormState) {
  const errors: Partial<Record<keyof FormState, string>> = {}
  if (form.username.trim().length < 3) errors.username = '至少 3 个字符'
  if (!/^\S+@\S+\.\S+$/.test(form.email)) errors.email = '邮箱格式不对'
  if (form.password.length < 6) errors.password = '至少 6 位'
  if (form.password !== form.confirm) errors.confirm = '两次密码不一致'
  if (!form.agree) errors.agree = '必须同意条款'
  return errors
}
```

- `onSubmit` 里 `e.preventDefault()`
- 错误对象是派生值，render 时算；不要存进 state
- `disabled={Object.keys(errors).length > 0}` 禁用提交
- 原生校验会干扰自定义校验时，加 `noValidate`

### 1.5 Vue 对照

| Vue | React |
|---|---|
| `v-model="form.name"` | `value={form.name}` + `onChange` |
| `v-model.trim` | `onChange` 里 `value.trim()` |
| `v-model.number` | 保留字符串，提交时 `Number()` |
| `v-model.lazy` | 用 `onBlur` 或手动控制 |
| `@submit.prevent` | `e.preventDefault()` |
| `reactive` 表单对象 | `useState` 对象 + 不可变更新 |
| `defineModel` | 受控 props + 回调 |

`v-model` 是语法糖：`value` + `input` 事件。React 把它拆开，所以格式化、校验、联动都更显式。

### 1.6 常见坑

1. 受控组件只写 `value` 不写 `onChange` → 只读
2. `value` 从有到无（undefined）→ 受控/非受控切换警告
3. checkbox 用 `value` 而不是 `checked`
4. 直接改 `form.name` → 不重渲染
5. 文件输入试图设 `value` → 不允许
6. 把错误/派生值存进 state → 双份数据

### 我的实现 / 遇到的问题

已完成 `src/components/day015/`：`ControlledRegistrationForm` / `UncontrolledLoginForm`。

**受控注册表单：**

- 一个对象 state + `handleChange(key, value)` 更新
- 文本 / textarea / select / radio 组 / checkbox 全部受控
- `validate(form)` 派生 errors；`submitted` 只控制显示
- `noValidate` + `onSubmit` + `type="submit"`；提交后显示错误或 JSON

**非受控登录表单：**

- `defaultValue` / `defaultChecked`，无 `value` / `onChange`
- `onSubmit` 里 `Object.fromEntries(new FormData(e.currentTarget))` 读取

**踩坑：**

- 最初用 button `onClick` + 全局 `MouseEvent`，类型不兼容；改为 form `onSubmit` + `React.SubmitEvent<HTMLFormElement>`
- 单条 `errText` 存 state 是反例；改为派生 errors 对象
- radio 必须是一组同 `name` 的选项；单个 radio 不对
- email 校验从 `endsWith('@qq.com')` 改为格式正则；age 的 NaN 要判无效

## 4. 总结与复习卡（10 min）

### 今日一句话总结

受控 = state 驱动 DOM（value + onChange，实时校验/联动）；非受控 = DOM 持有值（defaultValue + FormData，文件输入必须）；`v-model` 是 value + input 的语法糖，修饰符在 React 里手动实现。
