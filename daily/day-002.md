## 1. 核心概念（35 min）

### 1.1 心智模型：Vue 追踪数据，React 重放渲染

- Vue：Proxy 依赖收集 → 精确通知 → patch DOM（数据驱动、可变）
- React：`setState` 标记更新 → **重新执行组件函数** → 得到新的 element 树 → diff → commit（快照驱动、不可变）
- 关键结论：React 不追踪你读了哪个字段，只问「这个组件的状态变了吗」

### 1.2 render → commit

| 阶段 | 做什么 | 能否重复/中断 | 注意 |
|---|---|---|---|
| render（协调） | 执行组件函数、生成 element、reconcile Fiber | 可以（并发、StrictMode 双调用） | 必须纯：不请求、不改 DOM、不改外部变量 |
| commit | 应用 DOM 变更 → layout effect → 绘制 → passive effect | 一次性 | DOM 已就绪；`useLayoutEffect` 同步、`useEffect` 异步 |

### 1.3 状态是快照

```tsx
function handleClick() {
  setCount(count + 1)
  setCount(count + 1)      // 同一闭包里 count 仍是本次渲染的值
  console.log(count)       // 旧值：setState 不会改当前变量
}
```

- 每次渲染的函数作用域里，`count` 是常量
- 函数式更新 `setCount(c => c + 1)` 基于「待处理队列中的前一个值」

### 1.4 不可变更新

```tsx
// 错：引用没变，React 用 Object.is 比较后可能 bail out
todos.push(newTodo)
setTodos(todos)

// 对：产生新引用
setTodos([...todos, newTodo])
setTodos(todos.map(t => t.id === id ? { ...t, done: !t.done } : t))
setTodos(todos.filter(t => t.id !== id))
```

为什么不可变：引用比较是 React 判断「变了没有」的依据；也让并发渲染、时间旅行、memo 成为可能。

### 1.5 Vue 对照

| Vue | React | 关键差异 |
|---|---|---|
| `const count = ref(0)` | `const [count, setCount] = useState(0)` | React state 是渲染快照，不是长期可变的响应式容器 |
| `count.value++` | `setCount(c => c + 1)` | Vue 原地修改并自动通知；React 产生新值触发重渲染 |
| `computed` | 渲染期直接算（必要时 `useMemo`） | React 默认每次渲染重算，先别急着 memo |
| `watch` | `useEffect` / 事件回调 | Effect 是同步外部系统，不是派生状态 |
| 模板自动追踪依赖 | JSX 不追踪，整个组件函数重执行 | 重渲染范围默认是组件级 |
| 微任务批量刷新 | 自动批处理 + 并发调度 | React 19 默认自动批处理，可中断 |

### 1.6 常见坑与最佳实践

- 不要依赖「setState 后的旧闭包值」；连续更新用函数式更新
- 对象/数组一律不可变更新（spread / `map` / `filter` / `toSpliced`）
- 渲染期保持纯函数；日志、请求、DOM 操作放到事件或 Effect
- 重渲染 ≠ DOM 全量更新；render 之后还有 diff
- 组件内定义新对象/函数会破坏 `memo` 的浅比较，但不要默认上 `useMemo`/`useCallback`

### Vue 对照笔记（写在下面）

用 5–8 行说明：同样的 Todo 用 Vue 写，添加/切换/删除分别怎么写？为什么 Vue 里 `todos.push()` 能触发更新而 React 不能？

```
  const todos = ref([]);
  function addTodo(newItem) {
    todos.value.push(newItem)
  }
  function toggle(newItem) {
    newItem.done = !newItem.done
  }
  function del(id) {
    todos.value = todos.value.filter((v) => v.id !== id)
  }
```

- Vue：响应式系统拦截了数组的 `push` 等变异方法，自动触发依赖更新；但 `filter` / `map` 返回新数组，**仍要重新赋值**（`todos.value = ...`）。
- React：没有自动拦截，`Object.is` 做**引用比较**判断 state 是否变化；`push` 不改引用 → 不更新；所有更新都必须手动产生新引用。

### 我的实现 / 遇到的问题

最终实现（`projects/react-lab/src/components/TodoDemo.tsx`）：

```tsx
import { useState } from "react";
import type { Todo } from "../types";

const TodoDemo = () => {
  const [todos, setTodos] = useState<Todo[]>([]);
  const [text, setText] = useState("");

  console.log("[render] TodoDemo", todos);

  function handleKeydown(e: React.KeyboardEvent<HTMLInputElement>) {
    if (e.key === "Enter") {
      addTodo(text.trim());
    }
  }

  function addTodo(title: string) {
    if (title === "") return;
    setTodos((prev) => [
      ...prev,
      { id: crypto.randomUUID(), title, done: false },
    ]);
    setText("");
  }

  function delTodo(id: string) {
    setTodos((prev) => prev.filter((v) => v.id !== id));
  }

  function addTwo(title: string) {
    addTodo(title);
    addTodo(title);
  }

  function toggleTodoDone(id: string) {
    setTodos((prev) =>
      prev.map((v) => (v.id === id ? { ...v, done: !v.done } : v)),
    );
  }

  return (
    <>
      <div className="flex space-x-2">
        <input
          value={text}
          onKeyDown={(e) => handleKeydown(e)}
          onChange={(e) => setText(e.target.value)}
        />
        <button onClick={() => addTodo(text.trim())}>+</button>
        <button onClick={() => addTwo(text.trim())}>add two</button>
      </div>
      {todos.map((v) => (
        <div key={v.id}>
          <span
            style={{ textDecoration: v.done ? "line-through" : "" }}
            onClick={() => toggleTodoDone(v.id)}
          >
            {v.title}
          </span>
          <button onClick={() => delTodo(v.id)}>del</button>
        </div>
      ))}
    </>
  );
};

export default TodoDemo;
```

**实验 A（mutation）**：`todos.push(newTodo); setTodos(todos)` 点击后**无反应**。`push` 不改变数组引用，`Object.is` 判定相等，React 直接 bail out，不调度 render。

**实验 B（快照）**：错误写法连续两次 `setTodos([...todos, a])`、`setTodos([...todos, b])` 都基于同一份闭包快照，第二次覆盖第一次，只会加一条（保留 b）；改为 `setTodos(prev => [...prev, x])` 后两条都能加入——`addTwo` 已验证。

**过程中修掉的问题**：
1. `setTodoDone` 只展开外层数组，内部 `v.done = true` 原地修改 → 改成只克隆命中项
2. `delTodo` 谓词最初写成 `===`，会保留要删的那条 → 改为 `!==`
3. `addTodo` 校验用参数、存入却用闭包 `text` → 统一用 `title`
4. `toggleTodoDone` 对每一项都创建新对象 → 只对命中项生成新对象，保持其余项引用稳定

## 4. 总结与复习卡（10 min）

### 今日一句话总结

React 的状态是**渲染快照**：更新必须产生新引用，React 用 `Object.is` 判断变化，重新执行组件函数（render）后再提交 DOM（commit）；Vue 则用 Proxy 追踪依赖、精确通知组件。批处理决定“渲染几次”，快照决定“你读到哪个值”。
