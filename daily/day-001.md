## 0. 检索热身（10 min）

第一天没有 React 复习题，先用 Vue 经验热身（口头回答即可）：

1. Vue 中修改一个 `ref` 后，从数据变化到 DOM 更新，大致经历了哪些阶段？
   修改 `ref` 后，会被 vue3 的 proxy 中的 set 捕获到，从而执行 trigger 函数，在组件中 trigger 函数一般就是组件的 render 函数，会导致组件重新开始渲染，重新渲染过程中会通过比较新旧虚拟node来找到最优方案，最终通过dom api 来更新UI
2. 你用 Vue 时，`computed` 和 `watch` 分别在什么场景下使用？
   `computed` 用于获取需要缓存的计算结果，当 `computed` 内部的响应式数据未发生改变的时候，获取计算属性不会重新计算，直接从缓存中获取
   `watch` 用于检测响应式数据是否发生了变化，发生变化后可以执行传入的函数参数
3. 你目前用过哪些 React API？最不踏实的地方是什么？
   useState / useEffect / useContext / useMemo / useCallback
   最不踏实：性能是否最佳？是否是最佳实现？
